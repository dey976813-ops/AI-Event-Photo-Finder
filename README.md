# AI Unleashed

AI-Powered Event Photo Discovery System

## Problem Statement

During events, thousands of photographs are captured and stored
in a common collection. Finding a particular person's photos
manually is time-consuming.

Our system uses AI-based face recognition and similarity search
to automatically identify and retrieve a user's photographs
from an event photo collection.

## Technology Stack

Frontend: React + Vite
Backend: Node.js + Express
AI Service: Python + FastAPI
Face Recognition: InsightFace / ArcFace
Database: Supabase PostgreSQL
Vector Search: pgvector
Storage: Supabase Storage
